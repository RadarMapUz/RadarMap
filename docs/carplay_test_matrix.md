# CarPlay: матрица случаев и ручной протокол

Редакция 05.11.2026, ветка `plan/49-carplay-qa` от main `9460ca99` (2.2.44, сборка 140).

## Как читать

**Чем закрыт** — одна из четырёх меток:

| Метка | Что значит |
|---|---|
| **Т** | Логика закрыта юнит-тестом. Руками смотреть не нужно, только при регрессии. |
| **Т+Р** | Решение закрыто тестом. Вид, время и поведение системы CarPlay проверяются руками в CarPlay Simulator с телефоном. |
| **Р** | Только руками в CarPlay Simulator с телефоном. Чистого правила нет, или поведение определяет система. |
| **М** | Только в машине: езда, сенсорный экран, беспроводной CarPlay, приборка BYD. |

**Тест** указан как `Файл/тест`. Новые файлы этого прохода:
- `CarPlayScenarioConnectTests` (CSC) — подключение и фаза маршрута цепочкой `CarPlayRootWatch` → `NavigationFlow` → `CarPlayTripPreview`;
- `CarPlayScenarioControlsTests` (CSK) — осмотр, щипок и двойные касания через настоящую `CarPlayMapModel`, очередь баннеров;
- `CarPlayScenarioDriveTests` (CSD) — секунда за секундой: оценки в машину, камера карты, нагрев, лента 3D за 2 ч, разницы стиля.

**Журнал**: `Log.carplay`, подсистема `uz.radarmap.ios`, категория `carplay`. В таблицах — начало строки, как она пишется в журнал. Строка здоровья «карта машина: …», «карта плитка: …» или «карта приборка: …» пишется раз в `engineHealthLogSeconds`: 10 с, после этапа 48 в релизе 30 с. Состав строки: приложение, сцена, экран телефона, спит, таймер кадров, кадров за N с, обновлений, ходов камеры, осмотр, поворот, наклон, курс, масштаб, камер в источнике, в кадре, кадров/с.

## Что вынести в чистые правила

Код этого прохода не правился. Случаи ниже остаются «руками», пока их правило встроено в делегат сцены. Каждое выносится в `nonisolated enum` с тестом, как `CarPlayRootWatch`.

| Правило | Где сейчас | Предлагаемая функция | Закроет |
|---|---|---|---|
| Строить ли окно: `shown && applicationState != .background`, иначе `needsFreshHost` | `CarPlaySceneDelegate.swift:164`, `CarPlayDashboardSceneDelegate.swift:69`, `sceneWillEnterForeground` | `CarPlayHostPolicy.install(onScreen:appInBackground:needsFresh:hasHost:) -> .build / .drop / .wait` (то же, что `CarPlayCluster.installsContent`, — одно правило на три поверхности) | П-4, С-1, У-5 |
| Можно ли начать сессию: `mayStartSession = !background \|\| guidingAtConnect`, условия старта в `sync()` | `CarPlaySceneDelegate+Flow.swift:21`, `CarPlayGuidance.swift` (`sync`, ~с. 400) | `CarPlayGuidancePolicy.startsSession(guiding:hasSession:mayStart:cancelledHere:metadataChanged:destinationChanged:)` | П-2, П-5, М-15, М-16 |
| Двойное нажатие ▶/■ и подтверждение ■ на ходу | `CarPlaySceneDelegate+Buttons.swift:115–134` | `CarPlayTripToggle.decide(last:now:active:speedKmh:authorized:) -> .noPermission / .ignore / .start / .confirmEnd / .end` | К-4, К-5 |
| Вопрос «ещё на месте?» только стоя | делегат, `carPlayQuestionMaxKmh` | в `ReportGuard` или `CarPlayBannerPolicy` | О-4 |
| Длительность баннера камеры: на экране — весь подъезд, поверх чужого — `carPlayCameraAlertSeconds` | `CarPlayCameraBanner.update` | `CarPlayCameraBannerText.duration(onScreen:)` | О-2 |

## Ручной протокол: CarPlay Simulator + iPhone 16 Pro по кабелю

Сборка из TestFlight, 2.2.44 или новее. Время — 35–40 минут. Все шаги выполняет владелец. На телефоне ничего не запускается автоматически.

### Подготовка (5 мин)

1. Mac: Xcode 27 → Window → Devices and Simulators → CarPlay Simulator (Device Hub). Пресет — «Widescreen Touch (RadarMap)», для части К — стандартный (Touchpad).
2. Телефон по кабелю, разблокирован, RadarMap из TestFlight. Геопозиция «Всегда».
3. Запомнить время начала по часам Mac: журнал снимается за последние 30 минут.
4. В RadarMap: маршрут не построен, поездка не идёт, адрес «Дом» задан (для шага 8).
5. На телефоне установлен Яндекс Навигатор или Карты с CarPlay (шаги 11–12).

### Сбор журнала

Запускает владелец, в течение 10 минут после шага 18:

```
sudo log collect --device-udid 00008140-0012489A1A6A801C --last 30m
```

Получится `system_logs.logarchive` в текущей папке.

### Фильтры

```
# Всё наше по CarPlay
log show system_logs.logarchive --style compact \
  --predicate 'subsystem == "uz.radarmap.ios" AND category == "carplay"'

# Жизненный цикл сцены и корень
log show system_logs.logarchive --style compact \
  --predicate 'subsystem == "uz.radarmap.ios" AND category == "carplay" AND (eventMessage BEGINSWITH "CarPlay " OR eventMessage BEGINSWITH "сцена машины" OR eventMessage BEGINSWITH "корневой шаблон" OR eventMessage BEGINSWITH "ведение" OR eventMessage BEGINSWITH "сессия заново" OR eventMessage BEGINSWITH "экран машины перерисован")'

# Строки здоровья трёх карт
log show system_logs.logarchive --style compact \
  --predicate 'subsystem == "uz.radarmap.ios" AND eventMessage BEGINSWITH "карта "'

# Тревоги: застывание, корень, осмотр
log show system_logs.logarchive --style compact \
  --predicate 'subsystem == "uz.radarmap.ios" AND messageType == fault'

# Хост CarPlay: окно показано или нет (норма — «Installing presentation view» и «Client needs visibility view»)
log show system_logs.logarchive --style compact \
  --predicate 'process == "CarPlayTemplateUIHost" AND (eventMessage CONTAINS "presentation view" OR eventMessage CONTAINS "visibility view")'

# Убийства процесса: сторож главного потока и память
log show system_logs.logarchive --style compact \
  --predicate '(process == "runningboardd" OR process == "SpringBoard" OR process == "ReportCrash") AND eventMessage CONTAINS "RadarMap" AND (eventMessage CONTAINS[c] "8badf00d" OR eventMessage CONTAINS[c] "watchdog" OR eventMessage CONTAINS[c] "jetsam" OR eventMessage CONTAINS[c] "memory")'
```
