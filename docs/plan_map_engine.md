# Сломанные дороги: причина, починка и другой движок

Написан по трём подряд жалобам на одно и то же — «дороги сломанные, не до
конца» — и по последней: «другую крутую технологию используй».

Главное вперёд: **дыры в дорогах были в ДАННЫХ, а не в рисовании.** Три раза
подряд чинили рендер, потому что дыра выглядит как ошибка рисования. Она ею не
была.

---

## 1. Почему дороги рвались

`build_roads.py` после склейки выбрасывал всё короче двадцати метров:

```python
def drop_stubs(roads, meters):
    return [r for r in roads if polyline_meters(r[2]) >= meters]
```

Правило написано против хвостов геометрии и дрожи мыши, и против них оно
верное. Но под него попадала и **перемычка** — кусок улицы между двумя
примыканиями. Их вокруг любой развязки полно: подъезд к перекрёстку, съезд,
вставка между разделёнными проезжими. Каждая такая перемычка удалялась, и на
её месте оставалась дыра ПОСРЕДИ улицы.

**Замерено на боевых тайлах прода**, квадрат 5×5 км по Ташкенту, 7 537 дорог:

| | число |
|---|---|
| разрывов на улицах класса ≤6 | **236** |
| на квадратный километр | **10,2** |
| из них на проспектах (класс 3) | 91 |
| на жилых улицах (класс 6) | 95 |
| порванных ИМЕНОВАННЫХ улиц | **38** |
| величина разрыва | 3,7–47 м, медиана 15,2 |

Порваны, среди прочих: Бунёдкор, Фурката, Беруний, Бобура, Абая, Афросиёб,
Ислама Каримова, Ќоратош. По городу это порядка **трёх тысяч четырёхсот дыр**.

Медиана 15,2 метра — ровно под порогом в двадцать. Совпадение исключено.

### Что исправлено

Обрубок — это **хвост**, а не перемычка. Кусок короче порога удаляется, только
если хотя бы один его конец ни к чему не примыкает; кусок, у которого оба конца
лежат в узлах сети, остаётся при любой длине.

Правка в `server/build_roads.py`, два теста в `server/test_build_roads.py`
(204 теста зелёные).

### Проверено сборкой, а не рассуждением

Вырезал из боевого экстракта центр Ташкента (28 539 дорог) и собрал тайлы
ДВАЖДЫ — старым правилом и новым:

| | старое правило | новое |
|---|---|---|
| дорог после склейки и отсева | 26 465 | **31 199** (+4 734) |
| разрывов в квадрате 5×5 км | **240** (10,4 на км²) | **53** (2,3 на км²) |
| порванных именованных улиц | **38** | **3** |
| вес наборов s+y на вырезке | 3,1 МБ | 3,9 МБ (+26 %) |

Семьдесят восемь процентов дыр исчезают. Оставшиеся пятьдесят три — другие
причины (края тайлов, честно отсутствующие в OSM куски), и это отдельная
работа.

Плата — четверть веса дорожных наборов. Ворота публикации (`roads_gate.py`)
считают изменение объёма больше ±12 % поводом остановиться, поэтому выкладка
пойдёт с явным `--allow-big-change` и причиной, а не молча.

## 2. Другой движок

Картинка на самописном холсте упирается не в скорость (кадр района — 7,4 мс), а
в картографию: расстановка подписей без наложений, порядок отрисовки по классам
через границы тайлов, интерполяция ширин по зуму, круглые стыки и торцы. Это
пишется годами и уже написано — в MapLibre.

### Что проверено, а не предположено

| | |
|---|---|
| Пакет | `maplibre-gl-native-distribution`, SPM, **6.29.0 от 24 августа 2026** |
| Лицензия | BSD-2, линковать в закрытое приложение можно |
| Вес | бинарник arm64 **7,8 МБ**, транзитивных зависимостей **ноль** |
| Минимальная iOS | 12.0 (у нас 18) |
| Наши тайлы | `mvt/{z}/{x}/{y}.mvt` подходят **как есть**: `gzip_static` уже отдаёт `Content-Encoding: gzip`, `ETag`, `Cache-Control` |
| Дырявая пирамида | 404 на тайл и 204 на диапазон глифов движок считает «пусто, не ошибка» — ровно наш диалект |
| Стиль | переносится из `server/static/editor_gl.js` дословно: все выражения и слои поддержаны |
| Глифы | наши 330 КБ читаются один в один |
| watchOS | среза нет — на часах самописный рендер остаётся |

### Чем платим и чего боимся

- **Правило «только фреймворки Apple» нарушается один раз.** Ровно один
  BSD-бинарник, который сам ничего не тянет.
- **Открытая беда движка (#3029)**: слежение за курсом + наклон 50–60° +
  `contentInset` дают до четырёхсот процентов процессора и нагрев. У нас
  `contentInset` не используется вовсе (точку взгляда сдвигаем арифметикой), а
  наклон держим на 45°. Проверять — на живом телефоне, не на симуляторе.
- **Батарея.** Ни одного опубликованного замера MapLibre iOS в навигационном
  режиме не нашлось. Мерить самим: Instruments Energy Log + `thermalState`.
- **Подпись данных — закрыто.** Индекс MVT теперь подписывается тем же ключом,
  а на телефоне стоит сторож (`EngineTileGuard`): он забирает тайл сам, считает
  sha256 и отдаёт движку только совпавшее. Нет индекса — нет карты, и это
  правильный отказ: пустая карта честнее подделанной. Осталось одно: индекс
  появится со СЛЕДУЮЩЕЙ сборкой — та, что идёт сейчас, стартовала до правки.
- **Офлайн.** Движку отдано двести мегабайт под кэш тайлов: уже виденное
  рисуется без связи. Полноценные offline-паки на регион — отдельная работа.

### Как сделано в коде

Третья подложка рядом с двумя существующими, за переключателем в настройках —
ровно так в проекте уже сделан переход панели.

| Файл | Что |
|---|---|
| `Features/Map/Engine/EngineMapStyle.swift` | стиль собирается кодом из `SketchPalette`: одна палитра на оба рендера, ничего не качается по сети |
| `Features/Map/Engine/EngineMapView.swift` | обёртка `MLNMapView`: камера по курсу, охват и наклон по ТЕМ ЖЕ правилам, что у схемы; камеры и маршрут — GeoJSON-слоями |
| `Features/Map/MapScreen.swift` | ветка `engineLayer`, курсор «я» своим слоем поверх |
| `App/AppSettings.swift` | `engineMap`, по умолчанию выключено |
| `server/publish_roads.sh` | глифы выкладываются в открытый вебрут рядом с MVT; индекс MVT подписывается тем же ключом |
| `server/build_mvt.py` | пишет `mvt_index_payload.json`: sha256 и размер каждого тайла |
| `Features/Map/Engine/EngineTileGuard.swift` | сторож в сессии движка: тайл попадает на экран, только если его sha256 сошёлся с подписанным индексом; нет индекса — карта пустая |
| `RadarMapTests/EngineMapStyleTests.swift` | стиль под тестом: шаблон адреса, два источника, кайма раньше полотна, круглые стыки, ширина из тайла, ни одного чужого хоста |

Два источника вместо одного диапазона: сборка пишет только зумы 15 и 11, и
источник, объявленный «11…15», гонял бы движок за 12, 13, 14, которых нет.

Весь код под `#if canImport(MapLibre)`: без пакета приложение собирается как
раньше. Это и есть выключатель.

## 3. Порядок

1. **Пересобрать страну и выложить** — это чинит три тысячи дыр и видно на
   ЛЮБОМ рендере, включая нынешний. Первое по важности.
2. Открыть проект в Xcode, дождаться подтяжки пакета, включить тумблер «Карта
   на движке» и проехать. Снять нагрев и расход.
3. Подписать индекс MVT — до того, как движок станет умолчанием.
4. Решать по замерам: остаётся движок или остаётся своя схема.

## 4. Чего не делать

**Не чинить рисованием то, чего нет в данных.** Это уже стоило трёх заходов:
полигоны, штрих, движок — а кусков дороги не было ни в одном из них.

**Не включать движок умолчанием до замера нагрева.** Приложение живёт в
держателе на солнце по три часа; это единственное, чего мы про движок не знаем.

**Не выбрасывать самописную схему.** Пока не пройдены пункты 2 и 3, она —
запасной аэродром, и стоит она ноль.
