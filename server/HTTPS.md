# HTTPS: сделано 11.08.2026

RadarMap живёт под **https://soulmed.uz/radarmap/** — на домене, который уже
был на этом сервере с сертификатом Let's Encrypt. Свой домен покупать не
пришлось, но это временное решение: адрес сервера вкомпилирован в приложение,
а `soulmed.uz` принадлежит другому проекту. Перед вторым релизом стоит завести
собственный.

## Как подключено

Одной строкой `include /etc/nginx/snippets/radarmap-location.conf;` внутрь
существующего server-блока домена (`/etc/nginx/sites-enabled/landing`, рядом с
`listen 443 ssl`). Ни один существующий `location` не тронут: `/radarmap/` —
более длинный префикс, чем `/`, и не пересекается с `/api/` лендинга.

**Откат — удаление одной строки.** Бэкапы конфигов лежат в
`/root/nginx-backup/`. После любой правки: `nginx -t && systemctl reload nginx`,
затем обязательно проверить, что живы соседи:

```
curl -sI https://soulmed.uz/ | head -1
curl -sI https://dentalor.uz/ | head -1
```

## Адреса

| что | адрес |
|---|---|
| База камер, лимиты, тайлы, пульт | `https://soulmed.uz/radarmap/…` |
| API краудсорса | `https://soulmed.uz/radarmap/api/…` |
| Маршрутизация OSRM | `https://soulmed.uz/radarmap/osrm/…` |
| Панель модератора | `https://soulmed.uz/radarmap/admin/` |
| Страница проекта | `https://soulmed.uz/radarmap/` |
| Политика (Privacy URL) | `https://soulmed.uz/radarmap/privacy.html` |

**Порт 8090 остаётся жить.** В App Store может уйти сборка со старым адресом;
выключить его — значит сломать её без возможности починить.

## Панель под префиксом

Снаружи она в `/radarmap/admin/`, внутрь запросы приходят уже без префикса
(слеш на конце `proxy_pass` его снимает). Обратно префикс подставляет сам
`admin.py` из `RADARMAP_ADMIN_BASE` — переменная прописана в юните
`radarmap-admin.service`. Без неё все ссылки и формы ведут в корень домена, то
есть на чужой сайт.

SSH-туннель остаётся запасным путём:
`ssh -L 8093:127.0.0.1:8093 root@45.130.148.94`, затем `http://127.0.0.1:8093/`
(там префикса нет, и он не нужен).

## Telegram

Токен и chat_id лежат в `/opt/radarmap/admin.conf` (права 600, в git не
попадают) — там же, где хэш пароля панели и ключ карт. Привязка чата:

1. Написать `@radarmapuz_bot` любое сообщение.
2. `bash /opt/radarmap/api/tg_bind.sh` на сервере.

Оттуда токен читают и `api.py` (письма из приложения, жалобы на камеры), и
`healthcheck.sh` (состояние сервиса). Сторож в cron проверяет уже домен, а не
localhost: смысл сторожа в том, чтобы видеть сервис глазами телефона.
