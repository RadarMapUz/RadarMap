# 🛰 RadarMap

**Карта камер видеофиксации Узбекистана + голосовой навигатор-антирадар.**
Нативное iOS-приложение: SwiftUI, iOS 26, тёмный «радар-детекторный» дизайн, максимальная экономия батареи.

> 3 341 камера из официальных открытых данных · маршруты по своему OSRM-серверу · лимиты скорости из OpenStreetMap · работает со свёрнутым приложением и погасшим экраном

---

## Возможности

### 🗺 Карта и данные
- **3 341 камера** (стационарные камеры, радары, «Интеллектуал+радар») из портала открытых данных data.egov.uz — база обновляется на сервере автоматически каждую ночь, приложение подтягивает изменения по воздуху
- Кластеризация на широких зумах, плавное «умное» панорамирование без подпрыгивания маркеров
- Свои камеры (локально) + **краудсорсинг передвижных радаров**: отметил — увидели все, подтверждения продлевают жизнь метки, дизлайки гасят
- Поиск мест, тёмная карта, режим «по ходу движения» (heading-up)

### 🔔 Оповещения
- Два режима геолокации: **тихий фон** (геозоны + significant location changes — почти ноль батареи) и **«Поездка»** (непрерывный GPS с активными оповещениями даже в фоне)
- Автостарт поездки за рулём (Core Motion), автозавершение после остановки
- **Умный радиус**: предупреждение за 22 секунды хода, а не за фиксированные метры
- Направленный фильтр: только камеры впереди по курсу (±70°)
- Полноэкранное предупреждение, эскалация сигналов, голос с направлением и скоростью, Live Activity в Dynamic Island

### 🧭 Навигация (свой роутинг!)
- Apple Maps не строит маршруты в Узбекистане — поэтому маршруты считает **собственный OSRM-сервер** на графе OpenStreetMap (Ташкент→Самарканд за 0,16 с)
- **Варианты маршрута** с числом камер на каждом — можно ехать там, где камер меньше
- **Голосовой turn-by-turn**: «через 600 метров — поверните направо», баннер манёвра, автоперестроение при съезде с маршрута, авто-финиш у цели
- Камеры вдоль маршрута списком + живая строка «камера через 450 м»
- Дом / Работа и недавние места — маршрут в один тап; повтор поездки из истории

### 🚫 Лимиты скорости
- 21 500+ участков дорог с ограничениями (maxspeed из OSM, извлекается на сервере)
- Знак лимита текущей дороги на HUD, пульсация и голос «Превышение скорости» с настраиваемым допуском

### 📊 Итоги
- Живые метрики поездки, **скорость прохождения каждой камеры** (зелёная/жёлтая/красная), история 50 поездок

### 🔋 Оптимизация
- Адаптивный GPS: вдали от камер и манёвров точность снижается — батарея живёт дольше
- Геометрия (коридор маршрута, матчинг лимитов) — вне главного потока; grid-индексы; кэши; предзагруженные звуки
- Ру́сский и узбекский языки (String Catalogs)

## Архитектура

```
RadarMap/
├── App/            AppEnvironment (DI), AppSettings, RootView
├── Models/         Camera, TripStats
├── Services/       LocationService (2 режима GPS), RouteService (Apple→OSRM),
│                   SpeedLimitService, CameraRepository, MobileCameraService,
│                   RemoteSyncService, MotionService, AlertPlayer, LiveActivityService
├── Features/       Map / Search / Trip / Settings / Onboarding — по фичам
├── DesignSystem/   Theme, компоненты
└── Resources/      cameras.json (встроенная база v3)
RadarMapWidgets/    Live Activity + домашний виджет
Shared/             Localizable.xcstrings (ru/uz), общие типы
```

- **SwiftUI + Observation** (`@Observable`/`@Environment`), default MainActor isolation
- Только нативные фреймворки: MapKit, CoreLocation, CoreMotion, AVFoundation, ActivityKit, WidgetKit

### Сервер (VPS, изолированно от других проектов)
- **nginx :8090** — статика (база камер, лимиты) + прокси
- **OSRM** (docker, алгоритм CH, `--mmap` — минимум RAM) — маршрутизация; карта Узбекистана с Geofabrik, автообновление графа ежемесячно
- **Crowdsourcing API** — Python stdlib + SQLite (systemd), рейт-лимиты, TTL меток
- Cron: ночное обновление базы камер с data.egov.uz (sha256-идемпотентно), ежемесячное обновление графа дорог и лимитов скорости
