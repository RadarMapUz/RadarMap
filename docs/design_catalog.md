# Каталог компонентов и правила интерфейса

Каталог — DEBUG-экран: ключ запуска `-designCatalog` (Xcode → Scheme → Arguments
или `simctl launch … -designCatalog`). Код — `RadarMap/DesignSystem/DesignCatalog.swift`,
там же `#Preview` на 375 pt (SE), ru/uz, день/ночь. Каждый компонент подписан
именем и правилом применения; переключатель «День / Ночь / Обе» вверху.

## Правила

1. **Одно главное действие на экран.** Жёлтая `PrimaryButton` — одна. Второе
   действие рядом — `SecondaryButton`; «Отмена» — `SecondaryButton(touch: .cancel)`.
   Необратимое — `PrimaryButton(tint: Theme.dangerFill)`.
2. **Мишень 44 pt.** Круги над картой — `controlCircle()` / `CircleControl`
   (`Theme.controlSize`); мелкая подпись-кнопка — `tapTarget()`. Растёт область
   касания, не глиф.
3. **Отклик — только `PressableStyle(роль)`.** Второго стиля нажатия не заводить,
   `UIImpactFeedbackGenerator` в действии кнопки не писать — силу даёт роль:

   | Роль | Вибрация | Где |
   |---|---|---|
   | `.regular` | лёгкая | круг над картой, док, плашка, второе действие |
   | `.primary` | средняя | «Поехали», «Начать поездку», «Отметить», тип отметки |
   | `.cancel` | мягкая | «✕», «Отмена», «Не сейчас» (`Button(role: .cancel)` — сам) |
   | `.choice` | щелчок выбора | чип варианта, режим, день календаря, период |
   | `.card` | лёгкая | карточка «Итогов» с переходом |
   | `.row` | щелчок выбора, без сжатия | строка списка |
   | `.ownFeedback` | нет | действие отвечает само: «Стоп», экран оповещения, «успех» |

   Вибрация — генератором UIKit (подготовлен на касании вниз), когда кнопка
   сработала, и ДО действия: кнопка, которая действием убирает себя с экрана
   (старт поездки, тип отметки), иначе осталась бы без неё; прокрутка списка не
   «жужжит». Недоступная кнопка приглушена стилем — своей `.opacity` к
   `.disabled` не добавлять. Исход действия (ушло / отказ / сохранено) — отдельным
   `UINotificationFeedbackGenerator` в действии; если он звучит сразу, кнопке —
   `.ownFeedback`, иначе две вибрации сливаются в дребезг. «Уменьшение движения» —
   без масштаба, только затемнение; системные вибрации выключены — молчит система.
   Чистое правило — `Models/TouchFeedback.swift`, тест `TouchFeedbackTests`.
4. **Не на горячем пути.** Ни анимаций, ни вибраций на тиках GPS. Вибрацию
   оповещения о камере (`AlertPlayer.haptic(level:)`) ничто не перекрывает:
   кнопки экрана оповещения — `.ownFeedback`.
5. **SF Symbols-эффекты — только о событии**: галочка ушедшей отметки (`bounce`),
   отказ «Отметить» (`wiggle`). Не для украшения.
6. **Тень — на фоне-форме**, никогда на составном виде: `statCard` (без тени),
   `liftedBackground`, `controlCircle`, `SolidPanel`. Без стекла и материалов над
   движущейся картой. Часто меняющиеся числа — `liveNumber()`.
7. **Цвета — только из `Theme`.** Хексов в экранах нет. Синий `accent` — текст и
   ссылки, `accentFill` — выбранное, жёлтый `action` — главное действие. Красный
   на карте — только камера. Новый токен — в `PaletteTests`.
8. **Вопрос на ходу — только `RoadPromptCard` через очередь `RoadPromptPolicy`.**
   На экране один вопрос; камера выше всех, под ней отсчёт стоит. В поездке
   вопросом становится панель поездки, «Стоп» на это время скрыт. Синяя —
   согласие, тихая — второе, строка «промолчите — …» всегда.
9. **«…» — плитки `TripMenuPanel` в слое меню над картой**, не `Menu` и не
   лист: места постоянные (`TripMenuSlots`), неприменимая плитка бледнеет.
