# Новый функционал: голос, штрафы, обслуживание, дальняя поездка (20.10.2026)

Решение владельца 20.10: берём четыре направления из совета. Android, страховые и
таксопарки, распознавание знаков — пока нет.

Общие правила для всех четырёх (как во всём приложении):
- решения — в чистых `nonisolated` движках с тестами; вьюхи только показывают;
- константы — в `AppConfig`, ключи — в `Storage`, сеть — через `APIClient`, строки — ru + uz;
- **предупреждение о камере главнее всего нового**: новый голос и баннер не перебивают и не задерживают камеру (очередь баннеров CarPlay, ворота голоса);
- личное (номер машины, пробег, документы, маршрут) с телефона не уходит; что уходит — названо явно;
- каждый пункт закрывается тестами, снимками SE/Pro Max × день/ночь × ru/uz и ревью.

## Этап 16. Узбекский голос записями

**Зачем.** Половина водителей говорит по-узбекски, а системный синтезатор произносит узбекские фразы с чужим акцентом. Голос — единственное, что водитель слышит за рулём. Если он звучит чужим, приложение кажется чужим.

**Как.** Диктор-носитель один раз записывает отрывки: слова, числа, расстояния, типы камер, манёвры. Приложение склеивает из них фразы без пауз. Если хоть одного отрывка нет, вся фраза идёт через синтезатор. Молчания не бывает никогда.

| # | Что | Готово, когда |
|---|---|---|
| 16.1 | **Сборщик фраз** (`VoiceComposer`, чистый): событие голоса (камера, расстояние, сторона, скорость/лимит, манёвр, пробка) → список отрывков на uz и ru. Расстояния округляются до записанных ступеней (50…900 м, 1; 1,5; 2 км…), числа собираются из десятков и единиц (65 = «oltmish besh»). Тест: каждая из 104 фраз в `docs/voice_phrases_uz.md` покрыта отрывками целиком | тест покрытия зелёный, нет фразы без полного набора |
| 16.2 | **Набор для диктора** (👤 запись): сценарий (id отрывка, текст, фраза-пример для интонации), имена файлов, тех. требования (WAV 48 кГц / 24 бит, моно, −16 LUFS, тишина по краям ≤ 50 мс), проверка папки записей (`tools/voice_kit/validate.py`: нет/лишние/громкость/клиппинг/длина), сборка в AAC + манифест с sha256 | диктору можно отдать один файл; проверка ловит пропуск и перегруз |
| 16.3 | **Плеер склейки**: `AVAudioEngine`, отрывки встык без щелчков, та же аудиосессия, что у голоса сейчас (`.voicePrompt`, приглушение музыки), `promptStyle` соблюдается (звонок → тон). Задержка до первого звука ≤ 150 мс, декодированные отрывки в кэше. Нет отрывка или файл битый → синтезатор | замер задержки; тест «удалён отрывок → голос всё равно звучит» |
| 16.4 | **Настройка** «Голос: системный / записанный» (по умолчанию записанный для uz, когда пакет есть); пакет в приложении (≤ 3 МБ AAC) | снимки настройки ru/uz |
| 16.5 | **Пакет-заглушка** до записи: отрывки, сгенерированные синтезатором, — чтобы склейка, задержка и подмена проверялись уже сейчас; 👤 прослушивание носителем после записи | прогон поездки в симуляторе с пакетом-заглушкой |

👤 Владелец: найти диктора и записать (~150–200 отрывков, 2–3 часа студии), прослушать результат.

## Этап 17. Штрафы по номеру машины

**Зачем.** Это повод открывать приложение каждый день. Сейчас «Итоги» говорят: «возможный штраф, ждём». Пришёл ли он на самом деле, приложение не знает. Цель — увидеть пришедший штраф рядом с поездкой: камера, дата, скорость, сумма — и не пропустить срок оплаты.

**Источник — главный вопрос (👤).** Законного открытого API штрафов по номеру нет. Варианты:
- соглашение с my.gov.uz;
- соглашение с платёжным сервисом (Click, Payme), у которого такой запрос уже есть;
- без соглашения — ввод самим водителем: вставить текст СМС или уведомления о штрафе либо заполнить вручную.

Делаем последний вариант сейчас и закладываем место под источник.

| # | Что | Готово, когда |
|---|---|---|
| 17.1 | **Модель и сопоставление** (`FineMatch`, чистый): штраф (дата и время, место или адрес камеры, скорость, сумма, номер постановления) → проезд в истории: окно по времени, камера по месту, скорость согласуется. Найдено → «штраф пришёл» (обратное правилу «не пришёл», FineDismiss), рейтинг и «Где теряете баллы» не меняются | тесты: точное совпадение, две камеры рядом, нет проезда (штраф без поездки — тоже показываем) |
| 17.2 | **Ввод**: вставить текст (разбор известных форматов СМС и уведомлений; 👤 нужны 5–10 настоящих образцов без личных данных) и ручная форма | тесты разбора на образцах; на чужом тексте — честное «не распознали», без догадок |
| 17.3 | **Экран «Штрафы»**: пришедшие и ожидаемые, сумма, срок оплаты и льготный период (👤 подтвердить правила), напоминание об оплате (локальное), ссылка оплатить (👤 адрес) | снимки, напоминание приходит один раз |
| 17.4 | 👤 **Источник по номеру** — после соглашения: запрос с телефона прямо к источнику (не через наш сервер), номер — только туда | после соглашения |

Приватность: номер и штрафы хранятся только на телефоне. Номер уходит только в выбранный источник (17.4), и об этом сказано на экране.

## Этап 18. Обслуживание машины

**Зачем.** Пробег приложение и так считает по поездкам. Напомнить о замене масла, ОСАГО, техосмотре, газовом баллоне, разрешении на тонировку — это дёшево (всё на телефоне), полезно и возвращает человека в приложение без рекламы.

| # | Что | Готово, когда |
|---|---|---|
| 18.1 | **Модель** (`Maintenance`, чистый): одометр = введённый пробег + км поездок после ввода (`TripOdometer`); пункты с интервалом по км и/или дате: масло, фильтры, тормозная жидкость, ГРМ, газовый баллон (освидетельствование — 👤 срок), ОСАГО, техосмотр, разрешение на тонировку, доверенность, КАСКО; «пора», когда наступил первый из двух сроков; «скоро» — за 500 км / 14 дней | тесты: км раньше даты, дата раньше км, сброс «сделано сегодня», поездки до ввода пробега не считаются |
| 18.2 | **Экран**: Настройки → Машина → «Обслуживание»: список с полосой остатка, «Сделано сегодня», свой интервал; карточка в Итогах, когда что-то «пора» | снимки SE/Pro Max, ru/uz, день/ночь |
| 18.3 | **Напоминания**: локальные, не во время поездки (после стоянки или в 9:00), одно на пункт и порог, уважают выключатель | тест расписания; на ходу не приходит |

Приватность: всё только на телефоне; с iCloud (этап 15) — в зашифрованном виде.

## Этап 19. Дальняя поездка

**Зачем.** На трассах Ташкент — Фергана (перевал Камчик), Ташкент — Самарканд — Бухара люди едут часами, а связь пропадает. Снег и туман на перевале — самый опасный момент поездки. Нужное там — погода на перевале, заправки и метан по пути, карта без сети по всему маршруту.

| # | Что | Готово, когда |
|---|---|---|
| 19.1 | **Погода на трассах (сервер)**: `server/build_road_weather.py` (cron 30 мин) берёт open-meteo (бесплатно, CC BY 4.0 — в «Источники данных») для заданных точек (`server/road_weather_points.json`: Камчик, Тахтакарача, участки М39 и А373), считает опасность (снег, гололёд: t ≤ 0 и осадки, туман: видимость < 200 м, ветер), публикует `weather/roads.json`. Телефон качает файл целиком — где он находится, сервер не узнаёт | тесты разбора и порогов на записанном ответе |
| 19.2 | **Предупреждение о перевале** (`RoadWeatherAlert`, чистый): маршрут или трасса по ходу проходит через опасную точку → баннер и одна спокойная фраза («На перевале Камчик туман») за 20–40 км; без маршрута — по ходу на трассе; ниже камеры в очереди голоса и баннеров CarPlay; данные старше 2 ч — молчим | тесты: на пути / не на пути / устарело / камера рядом — камера первой |
| 19.3 | **Коридор маршрута**: маршрут > 100 км → предложить скачать области карты по пути (`OfflineMapService`) и проверить граф без сети; «По пути»: заправки по топливу машины (метан со статусом), гостиницы, кафе в 2 км от маршрута по порядку вдоль пути; тап → заезд (`addStop`) | снимки; тест порядка вдоль маршрута |
| 19.4 | 👤 **Перекрытие перевала**: объявление пульта (`config.json`) + отметки «перекрыто» от водителей; проверить, что закрытый Камчик виден на маршруте | проверка владельцем |

👤 Владелец: список точек (проверить), деплой cron погоды, атрибуция open-meteo.

## Порядок

Параллельно, каждый этап — свой агент, ветка `plan/<номер>-*` и симулятор. В main — после полного прогона тестов.

1. **18** (всё в нашей власти, 2–3 дня) и **16.1–16.3, 16.5** (голос без диктора) — сразу.
2. **17.1–17.3** — сразу. 17.2 разбирает образцы, когда они будут, а до тех пор работает ручной ввод.
3. **19.1–19.3** — сразу. Сервер — без деплоя.
4. 👤 запись диктора, источник штрафов, деплой погоды.
