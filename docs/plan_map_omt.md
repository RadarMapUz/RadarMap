# План: карта «как у Яндекса» — OpenMapTiles + наши слои

Написан 28.09.2026. Прототип проверен в браузере (MapLibre GL JS — тот же
движок, что MapLibre Native в приложении) на перекрёстках Навои × Рашидов,
Навои × Лабзак, мост через Анхор и на обзоре Ташкента.

## 0. Почему так

Самописная картография (build_roads → MVT) месяц давала кляксы, иглы и
«шахматку» и рядом со снимком Яндекса не годилась (docs/plan_map_geometry.md).
Яндекс рисуют картографы вручную; повторить это из осевых OSM своим кодом —
годы. Отраслевой путь — **OpenMapTiles** (схема, на которой работают MapTiler,
Stadia, Protomaps) из тех же данных OSM, собранный у нас, с профессиональным
стилем, и **наши** слои поверх — там, где у нас есть то, чего нет ни у кого:
разметка полос, разделительные, зебры, площади перекрёстков, светофоры, камеры.

Ничего чужого в рантайме: тайлы, шрифты, иконки и стиль — с нашего сервера,
индекс тайлов подписан ключом владельца, телефон проверяет sha каждого тайла
(как сейчас mvt_index, ARCHITECTURE.md правило 19).

Объёмы: основа Узбекистана — 191 МБ (mbtiles, gzip), ~0,8 ГБ распакованных
тайлов на сервере (nginx жмёт при отдаче).

## 3. Приложение (нужен Xcode — в сессии 28.09 его инструментов не было)

1. **Стиль.** `EngineMapStyle.json(...)` собирает JSON сам. Новый режим:
   взять стиль из `make_style.py` как ресурс сборки (`Resources/map_style.json`,
   генерируется тем же скриптом с базой `AppConfig.syncBaseURL`), дописать к
   нему свои живые источники (`cameras`, `route`, `traveled`, `maneuver`,
   `position`) и их слои — они уже есть в `EngineMapStyle.layers(...)`.
   Тёмная тема: второй вызов `make_style.py` с ночной палитрой (фон
   `SketchPalette.groundTone`, асфальт из `asphaltTone`).
2. **Проверка тайлов.** `EngineTileGuard` сейчас знает один индекс
   (`mvt_index.json`, путь `/mvt/`). Добавить второй: `omt_index.json`, путь
   `/omt/`. Та же схема: подписанный конверт → `TileDigestIndex`, sha256 тела.
   Индекс основы ~165 тыс. записей — тот же бинарный формат `mvt_index.bin`,
   что уже решает проблему 23,5 МБ JSON.
3. **Шрифты и иконки.** `glyphs` и `sprite` — с нашего сервера; глифы
   `Noto Sans Regular/Bold/Italic` (сейчас на сервере только Regular, три
   диапазона — публикация кладёт все).
4. **Тесты.** `EngineMapStyleTests`: стиль парсится, у каждого слоя известный
   источник, свойства по типу слоя (тот же класс ошибок, что ловит
   `test_make_style.py`), наши слои над подложкой и под подписями.
5. **Выключатель.** Настройка `mapBase` (своя схема / OpenMapTiles) рядом с
   `engineMap` — откат без релиза, пока основа не проверена на телефоне.
