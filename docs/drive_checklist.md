# Контрольная поездка — чек-лист (база v10)

Переписана половина логики оповещений: коридор дороги, три градуса громкости,
ось моста, склейка поездок, умный старт, а сверху — разбор пропусков камер
(пять причин молчания, см. раздел ниже). До релиза это надо проверить настоящей
ездой. Один круг по городу + кусок трассы, ~30–40 минут.

## Перед выездом
- [ ] Приложение свежей сборки (внизу Настроек «База: v10»)
- [ ] Режим старта «Умный», оповещения «Авто», допуск +5
- [ ] Телефон в держателе, зарядка не обязательна (заодно смотрим батарею)

## Пропуски камер (главный тест)
Проверяем не громкость, а сам факт: камера видна и не исчезает. Смотрим на
панель HUD — расстояние должно убывать непрерывно.

- [ ] Знакомая камера на своей дороге: расстояние идёт **без разрывов** от
      входа в радиус до проезда. Раньше камера пропадала с панели в полосе
      примерно 120–180 м до неё (слепая зона проверки по куску дороги)
- [ ] Камера на **обратной стороне** разделённой дороги (та, что снимает оба
      направления): предупреждение есть, камера в HUD
- [ ] С активным маршрутом: камера по маршруту не пропадает нигде
- [ ] Плотный центр, едем 3–4 км без остановки: камеры продолжают появляться
      одна за другой, без «провала» через полтора километра
- [ ] Повернуть на улицу, где камера уже в 100–150 м: **один голосовой анонс**
      (раньше поздно замеченная камера молчала совсем)
- [ ] После поездки Итоги → карта проездов: проезды сосчитаны, включая те
      камеры, что раньше терялись

Важно про громкость, чтобы не спутать с пропуском: в городе на режиме «Авто»
и без превышения приложение молчит НАМЕРЕННО — камеру показывает панель и один
мягкий тук. Чтобы услышать голос в городе, поставь режим «Трасса» или проверяй
голос на превышении.

## Мост (главный тест — Малая кольцевая над пр. Темура)
- [ ] Проехать по мосту над камерой: **тишина**, камера не появляется в HUD
- [ ] После поездки открыть Итоги → карту проездов: моста в проездах **нет**
- [ ] Старое ложное «83/60» из истории **исчезло** (ретро-чистка на первом запуске)
- [ ] Проехать ПО проспекту под мостом: камера алертит как обычно

## Город (в лимите)
- [ ] Знакомая камера: тихо — только панель + один мягкий тук, без голоса
- [ ] Параллельная улица: камеры соседней дороги не алертят
- [ ] Превысить на ~3 км/ч на пару секунд: по-прежнему тихо (не «орёт с +1»)

## Превышение (осторожно, на пустой дороге)
- [ ] Устойчиво +10..15 сверх лимита у камеры: **сирена + голос со скоростью
      и лимитом** («ваша скорость 78, лимит 60»)
- [ ] Сбросить скорость: следующая камера в лимите — снова тихо

## Трасса
- [ ] Выезд на трассу: чип режима на HUD сменился на «трассу» (~3 мин)
- [ ] Камера на трассе в лимите: **один спокойный анонс**, без бипов
- [ ] Новые камеры A380/M37 из v7 на месте (если едешь в ту сторону)

## Заезд по пути
- [ ] Остановиться у магазина 5–10 мин, поехать дальше: в истории **одна**
      поездка с бейджем «Остановок в пути: 1», средняя скорость не просела
- [ ] В деталке остановка видна с местом и временем, «Разделить здесь» на месте

## Завершение
- [ ] Выйти из машины, телефон в карман: через ~3 мин пуш «Поездка: N км …»
- [ ] Тап по пушу открывает Итоги
- [ ] Батарея: расход за поездку сопоставим с прошлыми замерами (~3–5%/час)

## Если что-то не так
Логи решений пишутся в Console.app по подсистеме `uz.radarmap.ios`
(категории alerts / trips / sync). Скриншот + время момента — и я разберу,
какой порог крутить (ось 55°, коридор 30/55 м, устойчивость 2.5 с).
