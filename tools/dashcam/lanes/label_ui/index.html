Кадр – Размечено 0 / 0, пропущено 0 Время на кадр: среднее – с, медиана – с Сейчас: 0 с
1 сплошная · 2 прерывистая · 3 двойная · 4 бордюр (верхняя кромка) — класс выбранной линии или новой
5 припаркованная · 6 движущаяся машина — класс рамки; B — нарисовать рамку (тянуть мышью)
N новая линия: щелчки — узлы, Enter/N — готово, Esc — отмена
Тянуть узел — двигать; Shift+щелчок по линии — новый узел; двойной щелчок по узлу — удалить узел
Щелчок по линии/рамке — выбрать; Del/Backspace — удалить выбранное; Z — отменить
Пробел — сохранить и следующий неразмеченный; X — кадр непригоден (пропуск)
←/→ — предыдущий/следующий без сохранения; R — вернуть предзаполнение
T — принять перенос с соседнего кадра (пунктир); V — увеличить дорогу; H — скрыть разметку
