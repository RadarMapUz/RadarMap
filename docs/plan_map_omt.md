# План: карта «как у Яндекса» — OpenMapTiles + наши слои

Написан 28.09.2026. Прототип проверен в браузере (MapLibre GL JS — тот же
движок, что MapLibre Native в приложении) на перекрёстках Навои × Рашидов,
Навои × Лабзак, мост через Анхор и на обзоре Ташкента.

## 0. Почему так

Самописная картография (build_roads → MVT) месяц давала кляксы, иглы и
«шахматку» и рядом со снимком Яндекса не годилась (docs/plan_map_geometry.md).
Яндекс рисуют картографы вручную; повторить это из осевых OSM своим кодом —
годы. Отраслевой путь — **OpenMapTiles** (схема, на которой работают MapTiler,
Stadia, Protomaps) из тех же данных OSM, собранный у нас, с профессиональным
стилем, и **наши** слои поверх — там, где у нас есть то, чего нет ни у кого:
разметка полос, разделительные, зебры, площади перекрёстков, светофоры, камеры.

Ничего чужого в рантайме: тайлы, шрифты, иконки и стиль — с нашего сервера,
индекс тайлов подписан ключом владельца, телефон проверяет sha каждого тайла
(как сейчас mvt_index, ARCHITECTURE.md правило 19).

## 3. Приложение — что сделать (нужна сессия с инструментами Xcode, ~3 дня)

Сейчас в приложении есть подложка «Карта RadarMap» (`MapBase.engine`,
MapLibre), но она рисует ТОЛЬКО наш MVT своим стилем из кода
(`EngineMapStyle.json`): линии дорог, разметка, узлы, разделительные. В ней
нет основы (вода, зелень, дома, подписи) и нет слоёв 27–28.09 (полотно
многоугольниками, галтели, «вафля», зебры линиями, стоп-линии, стрелки,
осевые, полоса разделительной поверх асфальта, запасная линия основы).

### 3.1 Стиль — вшитым ресурсом, не из сети
Правило 19: применяемое молча обязано быть подписано; стиль — это цвета и
порядок слоёв, и качать его неподписанным нельзя. Поэтому:
- `make_style.py --app` пишет `RadarMap/Resources/map_style_{light,dark}.json`
  с плейсхолдером `{{BASE}}` вместо адреса сервера (4 файла по ~70 КБ);
- `EngineMapStyle` берёт ресурс, подставляет `AppConfig.syncBaseURL`, дописывает
  живые слои приложения (камеры, маршрут, пройденное, манёвр, позиция — они
  уже есть в `EngineMapStyle.layers`) над нашими и под подписями;
- тест `test_make_style` сверяет, что ресурс в репо совпадает с генератором
  (забыть перегенерировать — красный тест, а не старая карта у водителя).

### 3.2 Иконки — в бинарнике, шрифты — с сервера
- sprite (128 КБ: стрелки полос, «вафля», светофор) кладётся в бандл и
  подключается локальным адресом — иконку стрелки нельзя подменять с сервера;
- шрифты (102 МБ всего, качаются диапазонами по мере надобности) — как сейчас,
  с сервера: геометрии и смысла они не несут.

### 3.3 Сторож тайлов — второй индекс
`EngineTileGuard` знает один индекс (`/mvt/` → `mvt_index`). Сделать таблицу
«префикс пути → индекс»: `/mvt/` → `mvt_index.json`, `/omt/` → `omt_index.json`;
тот же `TileDigestIndex`, тот же бинарный кэш (`omt_index.bin`). Пока индекс
основы не проверен — тайлы основы не пускаются (пустая основа честнее
подделанной), а наша дорога работает независимо.

### 3.4 Выключатель
`MapBase.engine` остаётся; внутри — «основа: своя схема / OpenMapTiles»,
по умолчанию старая до замеров на телефоне. Откат — без релиза.

### 3.5 Тесты и приёмка
- `EngineMapStyleTests`: ресурс парсится, у каждого слоя известный источник,
  плейсхолдер заменён, sprite локальный, наши слои над основой, живые слои над
  нашими, подписи сверху; запасная линия основы без maxzoom (как в
  `test_make_style`).
- `EngineTileGuardTests`: маршрутизация `/mvt/` и `/omt/` к своим индексам,
  неизвестный путь — отказ.
- На iPhone (Instruments): память карты, 60 кадров при ведении за машиной,
  нагрев за 20 минут в держателе; места — Навои × Рашидов, Мукими у «Новзы»,
  Бунёдкор × Сеул, Чирчик (вне Ташкента).
- CarPlay: `CarPlayMapView` на движке не переведён — отдельный шаг после
  приёмки на телефоне.
- TestFlight: поднять `CURRENT_PROJECT_VERSION` в репо (CLAUDE.md: номер сборки
  должен называть коммит).

### 3.6 Размер индексов — первое открытие
Два индекса — 50 МБ JSON (27 + 23,7) при первом включении карты; по мобильной
сети это много. Правильно — подписанные ОСКОЛКИ индекса по районам (z8,
~100 шт.): телефон качает индекс только своего района, сотни килобайт.
Сервер: `export_mbtiles.py`/`build_mvt.py` пишут осколки + подписанный список
осколков с их sha256 (одна подпись на всё, как у дорог). До этого — включать
карту по Wi-Fi.
