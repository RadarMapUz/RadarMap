# TestFlight 2.2.22 — проверка (перекрёстки, бордюры, развороты)

Стиль карты для новой сборки дорог (сборка страны 18.10). Углы, развороты и
носы разделительной видны и без обновления приложения — они в тайлах; бордюр
по углу и тихое зерно асфальта — только в этой сборке.

1. Перекрёсток двух проспектов (Нурафшон × Фаробий, 41.3376 69.2237): углы
   скруглены, жёлтая кромка проспекта идёт по дуге угла, а не обрывается до
   него. Ночью — приглушённым золотом.
2. Разворот на Нурафшон (41.3365 69.2222): разрыв разделительной — сплошной
   асфальт, без светлой щели и белой линии поперёк; нос разделительной ровный.
3. Вблизи (z19–20) асфальт перекрёстка без «грязной крошки».
4. Со старыми тайлами (до публикации дорог) карта выглядит как в 2.2.21 —
   новый слой бордюра просто пуст.
