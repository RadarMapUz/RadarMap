# Узбекский голос записью — набор для диктора и студии

Приложение говорит за рулём короткими фразами: «Statsionar radar oldinda
oʻngda, besh yuz metr», «Uch yuz metrdan soʻng, oʻngga buriling». Сейчас их
читает турецкий синтезатор, и звучит это чужим голосом. Здесь — всё, чтобы
носитель языка один раз записал **отрывки** (слова, числа, расстояния,
типы камер, манёвры), а приложение склеивало из них любую фразу.

Диктору отдаётся один файл — **`script_uz.csv`** — и раздел «Для диктора и
студии» ниже.

## Для диктора и студии

### Что записать

`script_uz.csv` — 145 строк, по строке на отрывок:

| колонка | что это |
|---|---|
| `id` | имя файла: `id` + `.wav` (например `dist.300.after.wav`) |
| `text` | что сказать — ровно это, ни словом больше |
| `example` | фраза, в которой отрывок прозвучит: прочитайте её про себя, чтобы взять верную интонацию |
| `position` | где в фразе стоит отрывок: начало / середина / конец / отдельно |
| `note` | особые указания (как читать «+», аббревиатуры) |

Как читать:

- **Одна строка — один файл.** Не склеивать два отрывка в один файл и не
  делить один на два.
- Ровно, спокойно, как навигатор: без эмоций и без «дикторской» подачи.
  Темп — обычной разговорной речи.
- **Интонация по колонке `position`.** «начало» и «середина» — ровно, без
  понижения в конце (за отрывком будет продолжение). «конец» и «отдельно» —
  с обычным завершением фразы. Где указано несколько мест — средняя, ровная
  интонация.
- Числительные (`num.*`) — ровным тоном: одна запись встаёт и в середину
  («yetmish besh»), и в конец фразы.
- `kind.intelligent_radar`: «+» читается как «va».
- `kind.dps_post`, `kind.accident`: аббревиатуры YPX и YTH — так, как их
  говорят вслух (уточнить с владельцем до записи).
- Все отрывки — **одна сессия, один микрофон, одно положение у микрофона.**
  Склейка соединяет записи вплотную: разница в тембре или громкости между
  днями записи будет слышна в каждой фразе.
- Ошиблись — перезапишите отрывок целиком; правку внутри файла не делать.

### Технические требования к файлам

| | требование |
|---|---|
| формат | WAV (PCM), **48 кГц, 24 бит, моно** |
| имя | `<id>.wav`, строчными, как в колонке `id` |
| громкость | **−16 LUFS** (integrated) на файл, допуск ±1,5 LU |
| пик | не выше **−1 dBFS**, без клиппинга |
| тишина по краям | **не больше 50 мс** в начале и в конце — но звук не обрезать: первый слог должен начинаться мягко, не с полуслова |
| обработка | без компрессии «в кирпич», без реверберации и музыки; лёгкий шумодав допустим, если не «булькает» |
| помещение | тихое, без эха (вокальная будка или заглушённая комната) |

Сдаётся одна папка со 145 файлами `.wav`. Студия может проверить её сама:

```sh
python3 validate.py путь/к/папке
```

Ошибки (пропущенный или лишний файл, не тот формат, клиппинг, громкость
мимо −16 больше чем на 3 LU, тишина по краям больше 50 мс, слишком
короткий или длинный файл) нужно исправить; предупреждения — посмотреть.

Оценка работы: ~145 отрывков, 1,5–2 часа студии с перезаписями.

## Для владельца: путь от студии до приложения

1. **Сценарий актуален.** Если меняли фразы в коде — `./export_script.sh`
   (тест `VoiceComposerTests.testScriptCSVMatchesCode` не даст забыть).
2. **Отдать** диктору `script_uz.csv` и раздел выше; договориться о
   чтении аббревиатур (YPX, YTH).
3. **Принять папку** и проверить: `python3 validate.py папка/` — код выхода 0.
4. **Собрать пакет** (AAC 48 кбит/с, ~1,6 МБ при бюджете 3 МБ):
   ```sh
   python3 build_pack.py папка/ --out ../../RadarMap/Resources/Voice/voice-uz.bundle --voice "Имя диктора"
   ```
   Сборка ещё раз проверяет папку, обрезает края до 12 мс, выравнивает
   громкость до −16 LUFS (пик ≤ −1 dBFS), кодирует в AAC и пишет
   `manifest.json` (id → файл, длительность, sha256).
5. **Собрать приложение**, на телефоне — Настройки → Оповещения и звук →
   «Голос оповещений: Записанный голос» (появляется сама, когда пакет есть;
   по умолчанию записанный включён для узбекского языка). Кнопка
   «Прослушать оповещение» говорит записью.
6. **Прослушать носителем** в поездке (симулятор с маршрутом тоже
   годится): склейки, ударения, числа. Плохой отрывок — перезаписать
   только его, пересобрать пакет (шаг 4).
7. Заглушку удалять не нужно: настоящий пакет главнее, а заглушка в
   выпуск не попадает.

## Что делает приложение

- Фраза описана событием (`VoiceEvent`), `VoiceComposer` собирает её из
  отрывков. Если хоть одного отрывка нет, файл битый (sha256 не сошёлся),
  не раскодировался или в фразе есть имя собственное (улица, название
  остановки) — **вся фраза** звучит синтезатором, как раньше. Половины
  фразы записью и молчания не бывает.
- Звонок в машине — короткий тон вместо фразы, Siri слушает — тишина
  (`promptStyle`), ровно как у синтезатора.
- Расстояния говорятся записанными ступенями: 50…350 м через 50, 400…900 м
  через 100, километр, полтора километра.

## Заглушка до записи

```sh
python3 make_placeholder.py
```

Генерирует все отрывки голосом `say` (турецкий Yelda — узбекского в macOS
нет), прогоняет их через ту же проверку и сборку и кладёт пакет
`RadarMap/Resources/Voice/voice-uz-placeholder.bundle` с пометкой
`placeholder: true`. Приложение берёт заглушку **только в отладочной
сборке** и только по переключателю «Заглушка записанного голоса (отладка)»
в настройках оповещений (или с ключом запуска `-voicePlaceholder`). В
выпуск папка не попадает (`EXCLUDED_SOURCE_FILE_NAMES` в Release).

## Файлы

| файл | что делает |
|---|---|
| `script_uz.csv` | сценарий диктора (выводится из кода, руками не править) |
| `script_ru.csv` | то же для русского — на будущее, механизм тот же |
| `export_script.sh`, `ExportScript.swift` | экспорт сценария из `VoiceEvent`/`VoiceComposer`/`VoiceScript` |
| `validate.py` | проверка папки записей |
| `build_pack.py` | сборка пакета AAC + `manifest.json` |
| `make_placeholder.py` | пакет-заглушка голосом `say` |
| `kit_audio.py` | WAV, громкость (BS.1770), края |
| `test_*.py` | тесты: `python3 -m unittest` |

Всё — стандартная библиотека Python; кодирование AAC — `afconvert` из macOS.
