# TestFlight 2.2.8 — что проверить

Основа — docs/carplay_research_2026-10-11.md.

1. Карточка манёвра («Куда» → место): стрелка И текст «Поверните налево
   на …», а не одно расстояние. Метаданные для приборки выключены.
2. Окно: сценарии из testflight-2.2.7.md (Яндекс + «Connected» выкл/вкл,
   переподключение с RadarMap на экране). Плюс с ЗАБЛОКИРОВАННЫМ телефоном.
3. Перетаскивание пальцем — только в машине с сенсором: CarPlay Simulator его
   не присылает (ограничение Apple). В журнале строки «перетаскивание
   пальцем: начало / сдвиг / конец».
4. Журнал при проблеме: «манёвр в машину: …», «сцена машины: foreground, …,
   приложение в фоне …», «корневой шаблон не показан…», «окно машины застыло…».
