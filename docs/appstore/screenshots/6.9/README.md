# Скриншоты App Store — 6.9″ (iPhone 17 Pro Max, 1320×2868)

Сборка 2.2.30 (125), палитра v5, русский интерфейс, сняты 22.10.2026 на симуляторе.
`raw/` — чистые кадры, `marketing/` — с подписью сверху (собирает
`tools/appstore/marketing_shots.py`, подписи — в его `CAPTIONS`). Все PNG RGB без альфы.
Для iPhone этого набора достаточно: меньшие размеры App Store Connect масштабирует сам.
