# CarPlay: поиск адреса — план 09.11.2026

Жалоба владельца: «поиска в карплейе нет, кнопки там нету». Строки кода — на коммите `7a9b640e` (2.2.46).

**Источники.** Заголовки CarPlay из SDK iOS 27.0, журналы и замеры из `docs/audit_carplay_2026-10-18.md` и `docs/carplay_research_2026-10-11.md`. PDF CarPlay Developer Guide в репо нет и в этот проход не читался: страницы («Рук. стр. N») взяты из цитат аудита 18.10. Всё, что опирается не на SDK и не на цитату, помечено **[не проверено]**.

## 1. Что есть: когда вход в поиск виден

Вход двухшаговый: лупа в баре → сетка «Куда» → плитка «Поиск».

| Состояние | Лупа в баре | Плитка «Поиск» | Где |
|---|---|---|---|
| Нет поездки, нет маршрута | есть | есть (3-я) | `+Buttons.swift:53-56`, `+Destinations.swift:87-103` |
| Поездка без маршрута | есть | есть | то же |
| Идёт маршрут | есть, заголовок сетки «Маршрут» | есть (6-я, после «Отменить», «Обзор», «Камеры», Дома, Работы) | `+Destinations.swift:45, 62-85` |
| Панорамирование | **нет**: бар — одна «Готово» | недоступна | `+Buttons.swift:46-48` |
| Выбор маршрута | **нет**: бар — одна «Отмена» | недоступна | `+Buttons.swift:49-51` |
| Стоянка | есть | активна | `+Destinations.swift:102` |
| Клавиатура ограничена (`.keyboard`) | есть | **выключена**, серая: «Поиск на стоянке», на узкой плитке просто «Поиск» | `+Destinations.swift:96-103` |
| Экран до показа корня | бар отправлен до шаблона | — | `CarPlaySceneDelegate.swift:213` |
| Повторный заход | бар заново в `sceneDidBecomeActive`, `templateDidAppear` | — | `CarPlaySceneDelegate.swift:518`, `+Window.swift:102` |
| Кэш `sentBar` | ключ `[поездка, маршрут, осмотр, выбор]`, сбрасывается `resendButtons` | — | `+Buttons.swift:41-42`, `+Pan.swift:83-87` |

**Ввод.**
- Клавиатура: только `CPSearchTemplate`, правила её показа — у системы. В API шаблона диктовки нет (`CPSearchTemplate.h`).
- Голос: Siri-фразы только «Домой» и «На работу» (`RadarIntents.swift:313-332`). Адрес голосом не задать.
- Недавние: плитками, сколько осталось мест в сетке из 8 (`+Destinations.swift:124`), всего хранится 8.
- Дом/Работа: плитки; незаданная открывает поиск, на ходу — окно с причиной (`+Destinations.swift:200-204`).

**Сенсор и ручка.** Кнопки шаблона рисует система, логика у нас одна. Выключенная плитка не нажимается на сенсоре; на ручке система, вероятно, и фокус на неё не ставит **[не проверено]**. Значит причина «на стоянке» видна только прочитавшему подпись, и только на широкой плитке.

## 2. Почему водитель мог не увидеть поиск

Журнала той поездки нет, поэтому какой из путей сработал у владельца — **предположение**. Сами пути доказаны кодом:

1. **Плитка мертва, пока машина ограничивает клавиатуру.** Ограничение задаёт машина (сигнал движения), а не наш порог скорости, и у разных марок ведёт себя по-разному **[не проверено на BYD]**. На светофоре плитка может остаться серой. Самая вероятная причина.
2. **Вход неочевиден.** Лупа ведёт не в поиск, а на сетку «Куда»; при маршруте поиск шестой.
3. **Лупы нет на двух экранах:** в осмотре и на выборе маршрута.
4. **Бар мог потеряться после подключения в фоне.** Корень, признанный без `templateDidAppear` (`+Window.swift:169-170`), не пересылает бар, а `templateDidAppear` такой путь и не приходит (журналы carplay4, carplay10). Бар, отправленный до показа шаблона, машина теряет (2.2.1/2.2.3). Тогда нет всех четырёх кнопок.
5. **Значение на старте может врать:** при включённом ограничении `limitedUserInterfaces`, прочитанное сразу в `didConnect`, по жалобе на форуме Apple 741142 бывает пустым. Ответа там нет **[не проверено]**. Читаем заново в момент касания.

**Попутно сломано в поиске:**
- «Найти» во время запроса к Apple показывает «Ничего не нашлось», хотя свои адреса уже есть: `lastResults` пишется только в самом конце (`CarPlaySearch.swift:294`).
- «Найти» дважды кладёт два списка: `pushSearchResults` без защиты (`+Destinations.swift:192`).
- Завис запрос Apple — шаблон ждёт ответ бесконечно и свои адреса не показывает (`CarPlaySearch.swift:290`).
- Свои ответы могут занять все 10 строк, и Apple не попадает в список (`:284-294`).
- Пустой ответ — пустой экран, без слов.
- Отключение машины не снимает идущий запрос.

## 3. Как должно быть

**Правило:** лупа есть в каждом состоянии, где разрешён выбор цели, то есть всегда. Запрещённое на ходу действие отвечает причиной и альтернативой, а не серой кнопкой.

**Бар**

| Состояние | Слева | Справа |
|---|---|---|
| Обычное | ▶/■, звук | лупа, «Отметить» |
| Осмотр | лупа | «Готово» |
| Выбор маршрута | «Отмена» | лупа |

Лупа в осмотре: сначала закрываем осмотр, потом открываем сетку, чтобы не класть шаблон поверх анимации. Правило «в осмотре выход кнопкой в баре» соблюдено; запрета на вторую кнопку в заголовках нет, по Руководству **[не проверено]**.

**Сетка «Куда».** «Поиск» — всегда первая плитка, всегда активна, одна подпись. Дальше «Отменить», «Обзор», «Камеры» (с маршрутом), Дом, Работа, заправки, недавние, всего не больше 8.

**Шаги до «Поехали».** Лупа → «Поиск» → ввод → строка → (при маршруте: «Заехать по пути» / «Новая цель») → стоя выбор вариантов → «Поехали». На ходу выбора нет, ведём рекомендованным (`CarPlayTripPreview.shouldPreview`, не менялось).

**Стоянка:** `CPSearchTemplate`. Свой индекс первым, Apple вторым, только со связью, не дольше 3 с. Apple получает не меньше трёх мест из списка, дубли убираем, свои выше.

**На ходу** (`.keyboard` в момент касания) — список «Поиск на ходу», заголовок секции — причина:
1. «Сказать адрес» — подсказка Siri, по касанию произносится вслух.
2. Дом, Работа (если заданы или выучены).
3. Недавние.
4. Категории: заправки по типу машины, аптека, банкомат, парковка, еда.

Всего не больше `CPListTemplate.maximumItemCount` на текущий момент. Машина встала, пока список открыт, — первой строкой появляется «Ввести адрес».

**Голос.** Новая фраза Siri «Найди адрес в RadarMap»: Siri спрашивает «Куда едем?», поиск тот же, маршрут к лучшему совпадению, ответ называет выбранное место. Свой `CPVoiceControlTemplate` с распознаванием речи — следующий шаг и решение владельца: новые разрешения (микрофон, распознавание) и борьба за звук с голосом камер.

**Пустые и ошибочные состояния** (строка в результатах, нажать нельзя)

| Случай | Заголовок | Подпись |
|---|---|---|
| Ничего, связь есть | Ничего не нашлось | Попробуйте адрес или название иначе |
| Ничего, связи нет | Ничего не нашлось | Без сети ищу только по своей карте. |
| Нет фикса, маршрут не построен | окно с причиной (как было) | |
