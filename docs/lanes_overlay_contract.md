# Полосы на перекрёстках: контракт данных (v1, 21.10.2026)

Единое описание для сервера (`server/build_lane_overlay.py`, `publish_lanes.sh`) и
телефона (`LaneOverlay`, `LaneOverlayService`). Меняется только вместе с версией `format`.

## Зачем

OSRM отдаёт полосы (`intersections[].lanes`) только там, где в OSM есть `turn:lanes`: на
12 маршрутах Ташкента — у 7 из 97 поворотов, у левых — у 1 из 26 (замер 21.10). Слой полос —
наш дополнительный источник: где OSRM молчит, телефон берёт полосы из подписанного файла.
Откуда данные в файле (разметка в OSM, объезд, регистратор, коммерческий набор) — для
телефона неважно; важно, что они прошли проверку и подпись владельца.

## Файлы на сервере

`/radarmap/lanes/lanes_index.json` — подписанный индекс (`SignedPayload`, ключ владельца,
тот же, что у базы камер и лимитов; на сервере ключа нет):

```json
{"format": 1, "version": 3,
 "files": [{"format": 1, "name": "lanes.<sha16>.json", "sha256": "<64 hex>", "bytes": 123456}]}
```

`/radarmap/lanes/lanes.<sha16>.json` — данные, без подписи; телефон сверяет sha256 и размер
с индексом. Имя по содержимому: старый файл живёт, пока на него ссылается старый индекс.

## Формат данных (`format: 1`)

```json
{"v": 1, "generated": 1792560000,
 "junctions": [
   {"id": "tash-0001",
    "lat": 41.31102, "lon": 69.27951,
    "bearing": 352, "tolerance": 30,
    "lanes": ["left", "left;straight", "straight", "straight", "straight;right"],
    "src": "survey", "checked": "2026-10-21"}
 ]}
```

| Поле | Смысл |
|---|---|
| `id` | устойчивый идентификатор подхода (для правок и отката) |
| `lat`, `lon` | точка стоп-линии / узла перекрёстка, 5 знаков |
| `bearing` | курс ВЪЕЗДА в перекрёсток по этому подходу, 0–359° (куда едет машина) |
| `tolerance` | допуск курса, ° (по умолчанию 30, не больше 45) |
| `lanes` | полосы слева направо; в каждой — стрелки через `;` в словаре OSRM: `left`, `slight left`, `sharp left`, `straight`, `slight right`, `right`, `sharp right`, `uturn`, `merge to left`, `merge to right`, `none` |
| `src` | `osm` / `survey` (объезд) / `dashcam` / `vendor` |
| `checked` | дата последней проверки |

Ограничения (сервер отвергает файл, телефон — запись): 1–8 полос; стрелки только из словаря;
координаты в Узбекистане; не больше 50 000 подходов и 8 МБ.

## Как телефон применяет

1. На манёвре без полос от OSRM ищется подход в 25 м от точки манёвра с курсом въезда в
   пределах `tolerance` от курса маршрута перед манёвром.
2. Нашёлся — полосы становятся `LaneHint` (как от OSRM); «наши» (`isValid`) — полосы, где есть
   стрелка в сторону манёвра (налево — `left`/`slight left`/`sharp left`/`uturn` для разворота).
   Дальше всё как с полосами OSRM: ряд стрелок, «Из двух левых рядов».
3. Не нашёлся — край по ПДД (20.2), как сейчас.
4. Полосы OSRM главнее слоя; слой — только где OSRM молчит.

Без файла, с битой подписью или sha — слоя нет (fail closed), всё работает как без него.
Выключатель — пульт `features.laneOverlay`.
