Разбор видео

A — принять, R — отклонить, ←/→ — соседняя находка

Кандидаты всех знаков, собранные в кластеры по похожести. Выберите класс для кластера целиком — подпись ляжет на все его вырезки. Смешанный кластер — «Разбить».

Быстрая разметка для обучения: на вырезке — то, что нашёл черновой детектор. Да (Y) — объект этого класса, нет (N), пропустить (S). Номера и лица размыты.

Кадр за 15–45 м до проезда камеры из GPX. Обведите мышью камеру (корпус на столбе/консоли) — можно несколько. Enter — сохранить, N — не видно, Backspace — убрать последнюю рамку. Из рамок обучится детектор камер.
