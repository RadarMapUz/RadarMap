# TestFlight 2.2.11 — что проверить

План и решения — docs/plan_commute_traffic_2026-10-11.md.

1. Итоги → сверху «Дорога на работу» и «Дорога домой» (появятся после
   нескольких поездок дом↔работа): время последней поездки, «на N мин
   дольше/быстрее обычного», «Обычно … , выезжаете около …», совет о
   времени выезда; тап — график и список поездок. Цифры сходятся с тем,
   что помните сами?
2. Главный экран: подсказка «Домой / На работу» показывает «обычно N мин».
3. Итоги в понедельник открываются на прошлой неделе, а не на пустой.
4. Иконки в Итогах: цветные круги по смыслу (камеры, дни, скорость, путь,
   серия) — читаются днём и ночью.
5. Пробки (только после выкладки сервера, см. ниже): слои карты → «Пробки»;
   цветные линии по направлениям; при маршруте — «+N мин из-за пробок» и
   цвет времени у вариантов. Пока данных мало — пробок на карте нет (так и
   задумано, без догадок).
6. Настройки → Конфиденциальность → «Помогать с пробками» — выключатель и
   текст о том, что уходит.

Сервер (с ОК владельца): deploy_api.sh → раздел nginx /radarmap/traffic/ →
deploy_traffic.sh; publish privacy.html.
