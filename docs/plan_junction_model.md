# План: перекрёсток по модели подходов (бордюры, островки, зебры)

Написан 06.10.2026 по снимкам владельца: Навои × Фуркат (площадь Хадра),
Навои × Олмазор/Абая, прямой участок Навои у Драмтеатра. Снимки Яндекса —
только эталон ВИДА для сверки глазами: данные с них не берём и автоматически
их карту не качаем (условия Яндекса). Сверка — так: владелец присылает снимок
места, мы рисуем своё там же нативным рендером (`server/omt/render_native.js`)
и правим ПРАВИЛА сборки.

## Что уже исправлено (06.10)

- направления проспекта не налезают друг на друга (подгонка по 10-му
  процентилю зазора) — пунктир больше не идёт вперемешку;
- узкая разделительная — бетонная полоса с бордюром; островки съездов — бетон;
- зебры жёлто-белые, с разрывом на разделительной;
- разделительная рвётся только на перекрёстке двух улиц и на развороте.

## Что ещё не так (Навои × Фуркат)

| | Образец | У нас |
|---|---|---|
| Площадь узла | компактная, между стоп-линиями | клякса ~120 м поперёк обоих направлений |
| Разделительная | доходит до центра узла, закруглённый нос | стёрта внутри кляксы |
| Зебры | на всех четырёх подходах | только на боковых |
| Углы | плавные дуги бордюра | ломаные хорды |
| Островки съездов | четыре бетонных «клюва» | крошечные или нет |

Причина одна: узел строится как оболочка точек вокруг кластера узлов графа,
а не из подходов. Всё остальное — следствие.

## Модель «устья» (5–7 дней)

1. **Подходы.** Для кластера узлов — список подходов: лента, её направление,
   ширина, полосы, есть ли у неё разделительная.
2. **Устье подхода** — поперечная линия на краю узла: зебра, если есть, иначе
   там, где кромки подходов расходятся. Стоп-линия и стрелки уже встают от
   зебры (сделано 06.10) — устье это обобщает.
3. **Площадь узла** = многоугольник по устьям + дуги бордюра между соседними
   подходами (радиус 8–15 м по классу), а не оболочка точек. Узел больше не
   залезает вдоль улицы.
4. **Разделительная** обрывается на устье носом-полукругом, а не стирается
   долей «в узле».
5. **Островки съездов** — грань между съездом и подходами, срезанная кромками
   лент (не по осям), бетон с бордюром поверх асфальта.
6. **Зебры на каждом подходе** со светофором, если в OSM есть переход
   рядом; иначе — по правилу «регулируемый перекрёсток в городе».
   Нарисованные OSM переходы остаются главными.

## Проверка

- Набор эталонных мест (снимки владельца): Навои × Фуркат, Навои × Абая,
  Чиланзар, Чорсу, Беруни × Саккичмон, Бунёдкор × Мукими — до/после
  каждого шага нативным рендером.
- Метрики (`road_metrics.py`): `dashes_in_junction`, `medians_on_asphalt`,
  `junction_spikes`; новые — «площадь узла на подход» (раздутые узлы) и
  «подходы со светофором без зебры».
- Публикация — как обычно, через ворота.

## Порядок

1. Подходы и устья (2 дня) — основа всего.
2. Площадь узла по устьям с дугами (2 дня).
3. Разделительная до устья с носом, островки съездов (1–2 дня).
4. Зебры на подходах (1 день).
